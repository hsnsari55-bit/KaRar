## Coding Rules

Never change project vision.

Never modify architecture without documentation.

Never delete working code without reason.

Always keep commits small and meaningful.

Follow existing coding style.

Prefer readable code over clever code.

---

## Development Principles

Every implementation must contribute to one of these modules:

- Geometry Engine
- Semantic Engine
- Topology Engine
- BIM Core
- IFC Export
- 3D Generator
- AI Decision System

Avoid unrelated features.

---

## Verification

Before completing a task:

- Verify implementation.
- Check for regressions.
- Update project documentation if required.

---

## Mission

Produce maintainable, testable and production-ready code that moves KaRar toward becoming a fully autonomous engineering platform.
